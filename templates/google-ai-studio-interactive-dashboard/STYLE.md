## 四幅可直接复用的图形组件

1. **Unit Matrix / 记录单位方阵**：每个方块正好对应一个样本记录，方块不能合并成热力图格。支持 All / Region / Tier / Segment 重分组。截图可见四区样本数量：148、121、87、56，总样本 **412**。图表数据表必须与可见方块总数相等。
2. **Diverging Likert / 五级情绪发散条**：非常不同意（红）/不同意（浅橘）/中立（灰）/同意（浅紫）/非常同意（紫）。灰色中性段一分为二，围绕对齐中心轴；统计两侧分别不计中性。支持按认同程度排序。
3. **Stacked Column Scrollytelling / 堆积柱滚动叙事**：多色分段、年度总计直标、2019–2026e，支持 Absolute / Share of total 和系列显示开关。**2026e 是估计值，使用斜纹，不能只靠颜色标记**。截图可见 2026e 合计 1840（单位 bn）。图表实际数值以模拟数据契约为准，不将截图中的品牌业务数字当作真实经营数据。
4. **Paired Dumbbell / 哑铃跨期图**：2024 空心黑边点、2026 紫色实心点，按一个共享的 0–75% 坐标展示；实心点位置可在空心点左右任一侧。差额使用 **pp（百分点）**，而不是“百分比增幅”。支持 By 2026 / By change / By 2024 排序。

## 极重要的视觉语法

- 扁平淡紫灰画布，**无影子、无大圆角、少用堆叠白色卡片**。
- 图表标题 14px 左右，正文 13px 左右；注释和轴 11–12px；黑色或深灰主文字。
- 状态切换：矩形按钮黑色 1px 边框，当前按钮黑底白字，非当前按钮透明底黑字。
- 细灰色坐标网格、稀疏直接标注、带边框的矩形浅底 tooltip；图例的色块和图内颜色一一对应。
- 估算数据用斜纹，反向变化用红色标注 + 负号，必要时同时给表格。
- **视图切换应改变计算与图形，不仅仅改变文字/配色**。
- 必须提供响应式重排、鼠标/键盘焦点和可核验的 HTML 明细表。

# T001｜Interactive Editorial Dashboard · 中文编辑式数据仪表板

## 来源与可信度
来源：Google AI Studio bundled `interactive-data-dashboard` 模板链接（见 template.json）。

**当前内容属于“对话提炼的设计理念 + 原创可执行规范”**：我们讨论过响应式 SVG、实时筛选、滚动式叙事和可访问数据表。**未直接验证原始页面视觉截图、具体图表类型、字体、颜色、CSS 或源码**。以下色彩与版式不是 Google 模板原貌声明。

## 四根设计支柱
1. **SVG 表达**：精细可控、矢量清晰；图形记号、直接标注、注释、比较基准均可独立设计。
2. **Live Filters**：全局筛选、局部筛选、跨图联动共享状态；清楚展示所选范围。
3. **Scrollytelling**：章节驱动视觉聚焦；读者可先看结论，也能跳出阅读顺序自由分析。
4. **Accessible Table**：任何重要图形都有数据表作为数值证据，表格保留数据粒度、字段、单位与排序。

## 原创推荐风格：Paper Editorial（非原站复刻）
- **底色**：暖白纸张感 `#F7F6F2`；高亮信息卡白色 `#FFFFFF`。
- **墨色**：近黑 `#20272B`；次级文字 `#667176`；分隔线 `#D9DEDD`。
- **聚焦色**：蓝绿 `#176F70`；浅聚焦底 `#E3F0EC`；提醒色 `#C56C41`。
- **字体**：系统中文无衬线，英文/数字使用系统等宽数字字体，避免依赖外链字体。
- **布局**：桌面 12 栏；章节编号（01 / 02 / 03）；大留白、窄阅读列、宽图表区。
- **文字**：标题回答业务问题，说明文本负责解释，图注放在图后面标明数据口径。
- **图形**：极细辅助网格（视觉对比低）；主系列 2–3px；直接注释关键拐点；不滥用颜色。
- **容器**：以分割线和留白为主，卡片和阴影为辅；不要满屏“仪表盘方块”。

## 推荐信息架构
```text
头部：栏目编号 / 主题主标题 / 问题摘要 / 最近更新时间
导航：总览 / 结构 / 异动 / 证据 / 行动
工具：时间 / 区域 / 品类 / 重置筛选
01 核心变化：KPI + 关键趋势（图文对应）
02 结构贡献：排序/贡献图 + 对业务解释
03 异常钻取：差异分布 + 明细表
04 决策建议：只在证据充分时输出建议
页脚：统计口径 / 数据来源 / 导出或复核入口
```

## 设计图形的约束
- 主要趋势优先折线/点图，排名优先水平条；注释要有锚点。
- 涨跌颜色不是绝对的好/坏，按指标语义定；强调必须有文字或符号。
- SVG 的坐标、annotation 和图表数据分层，避免 tooltip 承载一切。
- 需要展示大批量门店/商品时，先服务端聚合再渲染；明细表支持分页。

## 交互与动画
- 筛选组件同步 KPI、趋势、排名和表格；重置操作明确。
- 当滚动进入章节时，突出对应图形系列/注释；允许用户主动切换章节。
- 减少动效偏好时只保留静态状态；移动端转为图在上、文字在下。

## 适用场景
零售同店同比、销售增长归因、商品结构、采购达成、仓店库存与缺货、咨询式经营专题。

## 不适用与待核验
- 不适合把数千万条明细直接渲染为 SVG；应换用服务端计算、Canvas/WebGL 或采样。
- **未核验**：源模板究竟有哪些图型、其可访问性实现、动画节奏、具体字体颜色、实际框架。
