## 可执行规则（见 JSON）
- 样本方阵：每条记录一个离散方块、整型计数不丢记录、类别有固定色，标签格式“组名 · count (share%)”。不得只画一个矩形代表 N 条。
- 发散 Likert：5 段按顺序 sd,d,n,a,sa；中性段几何分成左右各 n/2，净不同意只取 sd+d，同意只取 a+sa。中心线固定。
- 堆积柱：按照年度和分组选定系列；每年度显式计算总值；按绝对值和百分比切换须重新计算 Y 轴；估计数据依赖斜线纹理 +“estimate”文字，不仅靠颜色。
- 哑铃：两期点分别为空心黑轮廓、实心紫；跨度正负都按原方向连线；差值 = after-before **pp**，不是 (after/before-1)%。
- 无圆角：默认 radius=0，button 为 1px 黑边，active 黑底白字。平整紫灰色背景和图形同纸面；不要加多余 shadow/玻璃态/渐变。
- 细网格、紧凑轴、直接标注关键点与变化值，悬浮框灰白底细黑边、无阴影。
- 行与列响应式：桌面保持图表可阅读宽度；窄屏横向可滚动图形 + 独立表格，不缩小为无法阅读的 SVG。

## 数据和状态核验
1. Unit: 148 + 121 + 87 + 56 = **412**；一张图 SVG 方块数和分组数量一致。
2. Likert: 各行 5 档数值合计 100；n/2 分配并保证其总量仅出现一次。
3. Stacked: 2026e 示例值 702+298+541+299 = 1840；选择系列后动态总计；占比归一化到100%。
4. Dumbbell: 31% → 62% 对应 +31pp；下降项 47% → 36% 对应 -11pp。
5. 显示色必须来自统一 token，不能无缘由将紫色替换成青绿；保持分类色跨图一致。
6. 四张图附 HTML 数据表及可访问名称和键盘聚焦标注。
7. 源网页未核验的动画细节、框架和其他图形必须在报告中注明未核验。
