# 08｜专业图形工程契约

## 图表应分为五层
`数据获取 → 指标口径/转换 → 图形语义 Spec → SVG/Canvas/WebGL Marks → 注释/交互/可访问表`

不得在可视化组件内部对数据库原始金额“顺手改口径”。

## 推荐 TypeScript 接口

```ts
type Evidence = "real" | "mock" | "unknown";
type ChartFamily = "trend" | "comparison" | "decomposition" |
                   "flow" | "composition" | "distribution" |
                   "retail" | "geospatial";
interface MetricDefinition {
  key: string;
  unit: string;
  formula: string;
  grain: string;
  timeRange: [string, string];
  denominator?: string;
}
interface DataVisualizationSpec {
  id: string;                       // 对应 charts/catalog.json 的 id
  title: string;                    // 结论性标题；没有真实证据只描述问题
  question: string;
  family: ChartFamily;
  dimensions: string[];
  measures: MetricDefinition[];
  encodings: Record<string, string>;  // x,y,color,size,shape,lineType
  annotations: {kind:string; value?:number; text:string;}[];
  transforms: {type:string; formula?:string;}[];
  interactions: string[];
  filters: Record<string, string | string[]>;
  source: {label:string; updatedAt?:string; evidence:Evidence};
  fallbackTable: boolean;
  responsive: {mobile:"stack"|"scroll"|"swap-chart"; minWidth?:number};
}
```

## 核心不变量（不可违背）
- **排序/条形**：长度编码的基线为 0；类别数太多时用滚动/TopN，保留合计/其他类。
- **差异**：两个时点同口径同样本；正负符号与图例清楚。
- **瀑布**：最终合计 = 初始值 + 各互斥因素增减；计算展示差额和不守恒告警。
- **漏斗**：对同 cohort 的顺序步骤计算条件转化率，明确基期。
- **桑基**：数值为非负流量；流入/流出不平衡时显示损耗/其他。
- **箱线/小提琴**：四分位及 KDE 算法、样本数、离群值规则写明。
- **热力图**：缺失、零、未来未发生三种情况分开编码。
- **地理图**：纬经度值合法；不能用地区地图面积冒充门店数差异。
- **时间**：时间格式、时区、自然日与营业日一致；同店同比样本筛选要提前完成。

## React 实现建议
```text
ChartPanel
 ├── ChartTitle (question + period + unit)
 ├── ChartToolbar (global/local filters + reset + download)
 ├── ChartVisual (renderer adapter / viewBox / resize)
 ├── AnnotationLayer (storytelling focus / thresholds / labels)
 ├── AccessibleNarrative (visible summary)
 └── SourceTable (keyboard access / pagination)
```

- SVG 中让每个关键 mark 可以通过 `<title>` 获得文本；添加标题、摘要、数据表。
- 工具提示在 hover、focus、touch 下都可使用。拖拽范围要有键盘或表单替代。
- 保留可见焦点与 `prefers-reduced-motion` 机制。
- 高密度图元或数万数据点：服务端聚合、viewport clipping、canvas 或 WebGL；不能把几千万行 StarRocks 数据直接灌给 SVG。

## 视觉令牌
配色按照模板 `tokens` 执行；结构、编码、统计规范由图表 spec 决定。避免把“颜值”当成有效性证明。
