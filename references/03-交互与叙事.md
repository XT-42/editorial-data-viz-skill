# 交互与滚动式数据叙事

## 导航模式
- **探索模式**：全局筛选常驻、图表卡片可任意操作、钻取层级清楚。
- **阅读模式**：章节滚动驱动画面状态；一个章节只聚焦一个数据变化和结论。
- **混合模式（默认）**：先导览重要发现，再开放全局筛选和详细交叉分析；滚动状态与用户手选状态不能相互覆盖。

## Scrollytelling 画面控制
- 每章有 `id`、`title`、`claim`、`activeChartState`、`annotation`、`evidence`。
- 桌面：左图右文或图文左右交错，图可 sticky，文字逐章滚动。
- 移动：图在上、章节卡在下；图始终可见；滚动由章节触发但仍可手动切换。
- 动画只用来说明“从旧到新/从总到分”；优先透明度/位置/高亮过渡，不强制复杂变形。
- `prefers-reduced-motion` 时禁用非必要动画，保持每个章节的静态可读性。
- IntersectionObserver 可驱动章节选中；React state、GSAP/Framer Motion 是可选实现，不应成为技术前提。

## 筛选状态范式
```text
GlobalFilters(dateRange, province, channel, category)
  ↓ derive visible data once
Chart A / Chart B / SummaryKPI / DetailTable
  ↑ crossFilter selection
```
- 保持单一的筛选状态来源（如 URL search params、Context 或 Zustand）。
- 用户点击图元时：显式展示“已筛选：品类=水饮”，可单独取消并一键重置。
- 日期要严格说明自然月、累计至昨日、同店同期或其他统计口径。
- 无数据/加载/失败/超范围/权限不足必须有状态区分。
- 给长任务、移动端和键盘操作提供输入替代方式，tooltip 不可作为唯一入口。

## 每个场景的交付约束
1. 标题：提出问题或结论（仅有真实证据时）。
2. 图形：一眼可见主要比较关系。
3. 注释：固定标出峰值、变化点、业务阈值或异动对象。
4. 证据：可打开表格、指标定义与来源。
5. 动作：给出后续可钻取维度，而非无证据的经营建议。
