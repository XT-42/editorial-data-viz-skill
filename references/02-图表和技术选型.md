# 图表与技术选型指南

## 先定分析任务，再挑图形
| 用户问题 | 首选图形 | 优先编码 | 避免 |
|---|---|---|---|
| 一段时间怎样变化 | 折线/面积/小倍数 | x=时间、y=同口径指标、重点直标 | 过多系列挤一张图 |
| 谁高谁低 | 排序横条/点图 | 位置与长度 | 3D 柱/被截断基线误导 |
| 增长是谁贡献 | 瀑布图/贡献排序 | 增量与正负贡献 | 把贡献率与同比增速混用 |
| 不同人群/门店是否有差异 | 箱线/分位带/蜂群 | 分布和样本数 | 只展示均值 |
| 两个指标是否相关 | 散点/六边形聚合 | x/y + 可选气泡面积 | 混淆相关与因果 |
| 结构与构成 | 堆积条/树图 | 份额、合计为 100% | 过量扇区与色彩 |
| 计划到完成的流向 | 桑基/漏斗/分层条 | 对齐流量口径 | 误把生命周期当流量 |
| 供应链关系 | 网络/层次/流程拓扑 | 节点、边及状态 | 仅为了炫技用自由力导图 |
| 区域/物流空间 | 地图 + 点/热力/轨迹 | 地点与时间粒度 | 用面积底图代表绝对值 |
| 精确核查和筛选 | 分析表/明细表 | 字段、格式、排序 | 只提供截图或 tooltip |

## 工具建议（非原网页技术栈判定）
- **D3.js**：自定义 SVG 比例尺、坐标、路径、注释、细致动效；图形数量很大时谨慎 DOM 性能。
- **visx**：在 React 中组装 SVG 原语，复杂布局与统一设计 token；适合差异化品牌图表。
- **ECharts**：需要成熟的丰富图型、联动及快速 BI 实现时，节省开发时间。
- **AntV G2**：统计编码与组合图形；**AntV S2**：多维透视明细。
- **TanStack Table**：自定义无样式表格；**AG Grid**：成熟的网格分析与企业功能，留意授权。
- **MapLibre + deck.gl**：门店地理和大量空间图形，关注地理底图许可。
- **Canvas/WebGL**：高密度图元/高频动画；不要追求所有图都用 SVG。

## 组件契约（图与数据分离）
```ts
interface ChartSpec {
  id: string;
  question: string;                 // 要回答的业务问题
  takeaway?: string;                // 有真实数据才能给结论
  type: 'line' | 'bar' | 'dot' | 'scatter' | 'map' | 'table' | 'custom';
  dimensions: string[];             // time / store / category / province 等
  measures: { key: string; unit: string; definition: string }[];
  filters: string[];
  comparison?: string;
  interaction: ('hover'|'click'|'brush'|'zoom'|'cross-filter')[];
  fallbackTable: boolean;
  evidenceStatus: 'real' | 'mock' | 'unknown';
}
```

## 分层架构
API 数据 → 口径归一化 → 派生指标与图形数据 → 筛选状态 → 可视化 mark → 注释层与可访问表格。图表组件不能直接承担数据库查询或隐含业务口径。
