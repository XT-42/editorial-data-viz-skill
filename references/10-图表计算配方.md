# 10｜专业图形计算与业务示例

以下全为示例逻辑，字段需按实际数据库适配。

## 1. Waterfall / 瀑布图
- 输入：`baseline`、`deltas: [{name, delta}]`、`final`。
- 算法：`running = baseline`；各步记录 `start=running, end=running+delta`，更新 running。
- 校验：`abs(running-final) <= tolerance`，允许浮点误差。桥接不守恒必须显示提示。
- 零售用途：销售额变化分解为门店数、同店增长、品类结构等。若因素之间交互不可简单相加，则需说明分解方法（如 Shapley 或替代方式）。

## 2. Dumbbell / 哑铃图
- 输入：`[{group, before, after}]`；先确认两个时间窗口的样本定义相同。
- 编码：两个圆点表示前后值，线段表示差额；差额在端点或标签直标。
- 排序：默认按差额绝对值降序，允许按 after 或业务优先级切换。

## 3. Cohort / 留存
- 定义：`retention(cohort, age)=active_users_at_age / cohort_initial_users`。
- 未来月份：`null` 而非零；初始样本必须展示；批次间年龄可比较，日历月不混用。
- 零售：新店生命周期、新品试卖、会员复购等，必须先定义“留存/活跃”。

## 4. Bullet / 目标达成
- 输入：`actual, target, ranges`；用主条表示实际值、细线表示目标。
- 背景区间：业务阈值必须真实来源，未提供阈值时不画自称“优秀/良好”的虚构区间。

## 5. Control Chart / 过程波动
- 输入：按时间排列的同口径指标、中心线及控制上下限。
- 若无足够统计过程数据，不准把 `mean ± 3*sd` 自动冒充可靠的 Shewhart 控制界限；需根据过程数据、分组和规则具体确定。
- 区分控制限（过程）和目标线（经营）。

## 6. Boxplot / 门店分布
- 输入：每个省份/门店群的原始数值、样本量。
- 输出：Q1、中位、Q3、须线及离群点；明确分位数计算和须线定义。
- 适合异常门店优先级筛选，不要只画平均值并称其为“分布”。

## 7. Sankey / 仓店流向
- 输入：`[{source,target,value}]`，单位必须一致且非负。
- 节点流入、流出守恒；若存在损耗，应单独建“损耗”边或显示注释。
- 当节点/边太多时做 TopN 合并或固定分层，禁止交叉线条淹没说明。

## 8. Scatter Quadrant / 价格带商品策略
- X：销量或 PSD；Y：毛利率；阈值为目标或分位点（明确来源）。
- 气泡面积如编码销售额要按面积比例映射，不可按半径比例。
- 四象限只是筛选工具，不能直接生成因果类建议。

## 9. Seasonal Matrix / 季节性
- 根据年×月或周×星期预聚合；标准化营业天数与门店数量。
- 高峰季节与节假日事件应单独标注，颜色只编码一个指标。

## 10. OTIF 双维分析
- X：on_time_rate；Y：in_full_rate；size：订单量。
- 真正 OTIF 按同一批订单中同时满足 on-time 和 in-full 的订单数 / 有效订单数计算，不能简单取两个比率平均。

完整 30 种图形的数据契约见 `charts/catalog.json`。
